# ふたりの将棋盤

ブラウザで動く、駒を自由に動かせる将棋盤です。友達と同じ盤面をリアルタイムで共有して対局できます。

- 駒を選んで移動先をクリックするだけの自由な盤（反則チェックなし）
- ルール切り替え：本将棋（玉を取ると勝ち・王手表示）／王手将棋（先に王手した側の勝ち）／判定なし
- 獅子：1手で玉の動きを2回できる駒。隣の駒を取って元のマスへ戻る動きにも対応
- 配置の編集：任意の駒の配置、持ち駒の増減、駒落ちや独自ルールの初期配置づくり
- 成り・不成の選択、一手戻す、棋譜の自動記録、盤の反転

HTML・CSS・JavaScript だけで動きます。ビルドは不要です。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構成 |
| `style.css` | 見た目（ライト／ダークテーマ対応） |
| `app.js` | 盤のロジックと同期処理 |
| `firebase-config.js` | Firebase の接続設定（オンライン対戦用） |
| `database.rules.json` | Firebase Realtime Database のセキュリティルール |

## 手元で動かす

`app.js` は ES モジュールなので、`index.html` をダブルクリックで開くのではなく、簡単なサーバー経由で開きます。

```sh
npx serve .
# または
python3 -m http.server 8000
```

Firebase を設定していない間は「ローカルのみ」と表示され、盤面はそのブラウザの中にだけ保存されます。

## オンライン対戦の設定（Firebase）

ブラウザ同士は直接通信できないため、盤面の受け渡しに Firebase Realtime Database を使います。無料の Spark プランで十分です。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成します。
2. 「構築 > Realtime Database」でデータベースを作成します（ロケーションはシンガポールなど近い場所を選びます）。
3. 「ルール」タブに `database.rules.json` の内容を貼り付けて公開します。
4. 「プロジェクトの設定 > マイアプリ」でウェブアプリを追加し、表示された設定値を `firebase-config.js` の `FIREBASE_CONFIG` に貼り付けます。`databaseURL` が含まれていることを確認してください。

Firebase の Web 用設定値（`apiKey` など）は公開しても問題ない値です。アクセスの制限は手順 3 のルールで行います。

## GitHub Pages で公開する

```sh
git init
git add .
git commit -m "ふたりの将棋盤"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

GitHub のリポジトリで「Settings > Pages」を開き、Source を「Deploy from a branch」、ブランチを `main` の `/ (root)` にして保存します。数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## 遊び方

1. ページを開くと、URL に `?room=xxxxxxxx` が自動で付きます。これが対局部屋です。
2. 「招待リンクをコピー」で URL をコピーして友達に送ります。
3. 同じ URL を開いた人どうしで、盤面がリアルタイムに同期されます。

新しい部屋を作りたいときは、URL の `?room=...` を消して開き直してください。

### 獅子の動かし方

1. 獅子を選んで隣のマスをクリック（1歩目。駒があれば取れる）
2. 青い印のマスから2歩目を選ぶ（元のマスに戻ることもできる）
3. 1歩で終えるときは「ここで止める」を押すか、獅子をもう一度クリック

2マス先を直接クリックすると、途中の駒を取らずに跳びます。

## 注意

- 部屋名を知っている人は誰でもその盤を動かせます。部屋名はランダムな文字列にしてあり、他の人に推測されにくくなっています。
- 同時に駒を動かした場合は、後から保存された方の盤面が残ります。
- 詰みや二歩などの反則は自動判定しません。
